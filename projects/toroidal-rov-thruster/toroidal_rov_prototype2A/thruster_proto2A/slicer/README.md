# Slicer handoff (resin)

No printer, resin or slicer profile is selected. `process_inputs.json` lists the unknown inputs. `conditional_resin_starting_points.json` is a human-readable starting record for a generic MSLA printer, not an importable profile or an authorisation to print.

Open only the four printable 3MFs (`rotor`, `duct_full`, `motor_support`, `hub_fit_coupon`). Select the resin maker's profile for your printer and set the orientations from `docs/PRINT_PREPARATION.md`. Inspect every layer for islands, suction cups and support access, then save the real slicer project here. Never print `REFERENCE_*` files as working parts.
